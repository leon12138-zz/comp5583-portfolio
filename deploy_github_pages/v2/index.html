01Coursework · DSAI5205

Natural Language Processing

TextCNN: A Simple CNN for Sentences

A completed two-slide technical presentation contribution on how a shallow convolutional network can classify sentences using pre-trained word vectors.

Evidence-informed context. DSAI5205 requires groups to use critical reading and discussion of academic literature. My completed segment focuses on Kim (2014), “Convolutional Neural Networks for Sentence Classification.”

My contribution. Prepared a two-slide technical overview of the two-channel TextCNN variant: 300-dimensional pre-trained word2vec vectors, one convolutional layer with 3-, 4- and 5-word filters, max-over-time pooling and a softmax classifier.

What the material shows. The presentation compares random, static, fine-tuned and two-channel word-vector settings. It records that pre-training is valuable and fine-tuning often helps, while two channels were not consistently better; local filters have limited span and max pooling discards exact positions.

Source basis: DSAI5205 reading guidance and the TextCNN presentation material.

02Proposed · COMP5523

Computer Vision

Vision-Based Intelligent Desk Organizer

A proposed group project for an overhead-camera system that inventories desk items, analyses their spatial arrangement and suggests a more logical layout.

Evidence-informed context. COMP5523 specifies a Vision-Based Intelligent Desk Organizer and Inventory Manager. The system should monitor a workspace from an overhead view and group similar objects while separating dissimilar ones.

My planned contribution. I plan to help define the object-detection and spatial-grouping pipeline, then turn detected item locations into clear text or on-screen reorganisation suggestions.

Planned system scope. The initial prototype will use a fixed overhead camera and a limited class set such as pens, notebooks, mugs, phones and keys. Its design will consider object detection/recognition, inventory and state monitoring, spatial cluster analysis, grouping logic and a suggestion engine.

Honest project status. This project remains under discussion and has not yet been implemented. When the team confirms the scope, evaluation should consider detection accuracy, spatial-logic reliability, suggestion validity and end-to-end latency.

Source basis: COMP5523 group-project specification.
