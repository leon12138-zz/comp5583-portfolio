01Coursework · DSAI5205

Natural Language Processing

TextCNN: A Simple CNN for Sentences

A focused technical reading and presentation contribution on how a shallow convolutional network can classify sentences using pre-trained word vectors.

ContextA DSAI5205 group reading assignment on a foundational NLP paper.

PurposeExplain how a shallow CNN can classify sentences and how pre-trained word vectors affect the approach.

My rolePrepared a technical presentation segment covering the two-channel TextCNN architecture, 300-dimensional pre-trained word2vec vectors, convolution filters and max-over-time pooling.

ScopeCompared random, static, fine-tuned and two-channel word-vector settings, alongside the paper’s stated strengths and limitations.

02Proposed · COMP5523

Computer Vision

Vision-Based Intelligent Desk Organizer

A proposed group project that uses an overhead camera to inventory desk items, understand their spatial arrangement, and suggest a more logical layout.

ContextA proposed COMP5523 group project. The team is still discussing its final scope and no implementation has begun.

PurposeBuild a vision-based workspace assistant that groups semantically similar desk items while separating dissimilar ones.

My planned roleHelp define the object-detection and spatial-grouping pipeline, then translate detected locations into text or on-screen reorganisation suggestions.

Initial scopeUse a fixed overhead camera and a limited class set such as pens, notebooks, mugs, phones and keys; later assess detection quality, suggestion validity and response time.
