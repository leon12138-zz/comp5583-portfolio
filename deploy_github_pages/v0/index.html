01Coursework · DSAI5205

Natural Language Processing

TextCNN: A Simple CNN for Sentences

A technical reading and presentation contribution on how a shallow convolutional network can classify sentences using pre-trained word vectors.

Purpose. Support a group reading assignment by explaining a core NLP method and its design choices clearly.

My contribution. Prepared a technical presentation segment based on Kim (2014), covering the two-channel TextCNN architecture, 300-dimensional pre-trained word2vec vectors, convolution filters, max-over-time pooling, and the model’s strengths and limitations.

Focus. Compared random, static, fine-tuned, and two-channel word-vector settings for sentence classification tasks such as sentiment and question-type classification.

02Proposed · COMP5523

Computer Vision

Vision-Based Intelligent Desk Organizer

A proposed group project that uses an overhead camera to inventory desk items, understand their spatial arrangement, and suggest a more logical layout.

Purpose. Build a vision-based workspace assistant that detects common desk items and groups semantically similar objects while separating dissimilar ones.

My planned contribution. I plan to help define the object-detection and spatial-grouping pipeline, then turn detected item locations into clear text or on-screen reorganisation suggestions.

Planned approach. Start with a fixed overhead camera, a limited class set such as pens, notebooks, mugs, phones, and keys, and evaluate detection quality, suggestion validity, and response time. This project is still under discussion and has not yet been implemented.
